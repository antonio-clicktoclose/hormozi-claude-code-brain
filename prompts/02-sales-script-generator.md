# Sales Script Generator

Use this prompt to generate a closing script based on Hormozi's Closing playbook.

## Prompt

```
Read the following playbook before responding:
- playbooks/$100M Playbook_ Closing -- Alex Hormozi -- $100M, 2025.md

Now build me a complete sales script for my business:

**What I sell:** [your offer]
**Price point:** [your price]
**Who I'm selling to:** [your ideal customer]
**Main objections I hear:** [list 2-3 common objections]
**The call format:** [discovery call / webinar close / DM close / in-person]

Generate:

1. Opening framework (rapport + frame setting) - first 2 minutes
2. Discovery questions that surface pain (5-7 questions in logical order)
3. The "gap" reveal - how to show them where they are vs. where they want to be
4. Transition to the pitch - the bridge sentence
5. Offer presentation structure (features > benefits > proof)
6. Objection handling scripts for each objection I listed
7. The close - 2-3 closing lines I can rotate
8. Post-close confirmation script to prevent buyer's remorse
```

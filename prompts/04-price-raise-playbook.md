# Price Raise Playbook

Use this prompt to plan and execute a price increase using Hormozi's Price Raise and Proof Checklist playbooks.

## Prompt

```
Read the following playbooks before responding:
- playbooks/$100M Playbook_ Price Raise -- Alex Hormozi -- $100M, 2025.md
- playbooks/$100M Playbook_ Proof Checklist -- Alex Hormozi -- $100M, 2025.md
- playbooks/$100M Playbook_ Pricing -- Alex Hormozi -- $100M, 2025.md

Now help me plan a price increase:

**My current offer:** [what you sell]
**Current price:** [what you charge]
**Target price:** [where you want to be]
**Number of current clients:** [how many active clients]
**Best client result:** [your best case study / testimonial]
**How long since last price change:** [months/years]

Generate:

1. A step-by-step price raise execution plan
2. What proof elements I need to collect BEFORE raising prices (using the Proof Checklist)
3. How to communicate the price change to:
   - Existing clients (grandfather them or transition?)
   - New prospects (positioning the new price)
4. What to ADD to the offer to justify the new price (without adding delivery cost)
5. The exact email/message template to announce the change
6. A timeline: what to do this week, this month, and next month
7. How to handle pushback or cancellation requests
```

# Ad & Content Hook Generator

Use this prompt to generate high-converting hooks and ad copy using Hormozi's GOATed Ads, Hooks, and Branding playbooks.

## Prompt

```
Read the following playbooks before responding:
- playbooks/$100M Playbook_ GOATed Ads -- Alex Hormozi -- 2025.md
- playbooks/$100M Playbook_ Hooks -- Alex Hormozi -- $100M, 2025.md
- playbooks/$100M Playbook_ Branding -- Alex Hormozi -- $100M, 2025.md

Now generate hooks and ad copy for my business:

**My business:** [what you sell]
**My target audience:** [who you serve]
**My best result / case study:** [specific numbers and outcomes]
**Platform:** [Facebook / Instagram / YouTube / LinkedIn / Email]
**Content type:** [ad / organic post / video script / email subject line]

Generate:

1. 10 scroll-stopping hooks using different hook frameworks:
   - Contrarian hook (challenges a common belief)
   - Result hook (leads with a specific number)
   - Story hook (opens with a relatable situation)
   - Question hook (asks something they can't ignore)
   - Authority hook (borrows credibility)

2. 3 complete ad scripts (short-form, under 150 words each):
   - Hook > Problem > Agitate > Solution > Proof > CTA
   - Each with a different angle

3. 5 video opening lines (first 3 seconds) for short-form content

4. 3 long-form ad variations (300+ words) for platforms that reward longer copy

5. A/B test recommendations: which 2 hooks to test first and why
```

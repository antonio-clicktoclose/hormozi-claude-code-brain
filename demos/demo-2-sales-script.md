## The Prompt

```
Read the following playbook before responding:
- playbooks/$100M Playbook_ Closing -- Alex Hormozi -- $100M, 2025.md

Build me a complete sales script for my business:

**What I sell:** Done-for-you marketing agency retainer (paid ads + funnel + email marketing)
**Price point:** $10,000/month
**Who I'm selling to:** E-commerce brand owners doing $500K-$2M/year who want to scale to $5M
**Main objections I hear:**
  - "That's a lot of money, I need to think about it"
  - "I've been burned by agencies before"
  - "Can't you just do a trial month at a lower price?"
**The call format:** 30-minute Zoom discovery call

Generate:

1. Opening framework (rapport + frame setting) - first 2 minutes
2. Discovery questions that surface pain (5-7 questions)
3. The "gap" reveal
4. Transition to the pitch
5. Offer presentation structure
6. Objection handling scripts for each objection I listed
7. The close - 2-3 closing lines
8. Post-close confirmation script
```
